Set up the assistant

The assistant uses Claude from Anthropic. It needs an API key on the server (never in the browser).

  1. Create a key at console.anthropic.com → API keys (add billing credit first).
  2. Add a line to .env in the project folder: ANTHROPIC_API_KEY=sk-ant-…
  3. Restart: node --env-file=.env server.mjs

What do you want to know?

It reads your products, saved scenarios and HMRC's live quota balances, and can price an order with the same engine as the order tool. It can't change anything.

Answers come from your data and live GOV.UK feeds via Claude. Estimates only — not customs advice. Check important figures in the app.
