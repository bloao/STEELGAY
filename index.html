Project mapping

Mapping out

Working space for the team to map what we have today and where each piece is heading. Add scope, data sources, flows, and open questions here as the shape of the project firms up.

What we have

Existing components, datasets, and reference material already in the repo.

  • Order intake form and initial scenario readout.
  • UK steel commodity code list (steel-commodities.js).
  • Trade remedy / safeguard measure lookup (steel-trade-measure.js).
  • Quota balance data (steel-quotas.js).

What we need to figure out

Open questions and unknowns the team is still resolving.

  • How CBAM inputs are sourced and validated.
  • Where working-capital and supplier exposure data comes from.
  • Which scenarios need to be persisted vs. one-off.

Approaches on the table

Candidate solutions to weigh up as a group.

  • Static reference data bundled with the app (current path).
  • Server-backed lookups via server.mjs for live tariff / quota data.
  • Hybrid: cached snapshots refreshed on a schedule.
